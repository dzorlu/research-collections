How each clipping method changes a tiny network

Definitions and data

r = p_now / p_old: the trainer now vs the trainer at rollout (drift). ρ = p_old / p_engine: the trainer vs the engine that sampled the token, same weights (mismatch). p_now is the probability of the sampled token under the current weights; p_old under the rollout weights W_old; p_engine under the engine's distribution q. The rollout (tokens, q, W_old) never changes; only the current weights move. The update is plain gradient descent: W ← W − lr · dW, with dW summed over all 8 positions. Hover a token to see only its part of the update on the network. Hover a connection for its numbers.

Notebook batch: rl-corrections/corrections.ipynb, torch seed 0, float64. "After drift" weights are W_old plus 0.25 × Gaussian noise, as in the notebook. Random: a seeded JavaScript generator with the same recipe.
